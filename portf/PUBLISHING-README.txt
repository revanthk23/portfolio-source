PERSONAL PORTFOLIO — NETLIFY UPLOAD

This folder contains the publishing-ready single-file website.

To publish with Netlify Drop:
1. Sign in to Netlify at https://app.netlify.com/drop
2. Drag the entire portfolio-netlify-upload folder onto the drop area.
3. Wait for Netlify to finish deploying.
4. Open the generated *.netlify.app URL.
5. Test navigation, the work/topic popups, both carousels, external social links, and the WhatsApp consultation form.

The existing design and contact details have been retained. The website is static; the consultation form opens WhatsApp with a prefilled message and does not store enquiries in a database.

The original source file is kept separately as index-original.html and is not included in this deployment folder.
